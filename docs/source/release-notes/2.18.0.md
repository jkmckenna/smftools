2.18.0 2026-07-30
Version 2.18.0 adds an engine-neutral semantic dependency planner for experiment and project workflows, transactional immutable preprocess generations with incremental compatibility-aware upgrades, and partition-native variant evidence, reporting, cohort metrics, and evidence-gated QC before deduplication. It also migrates the standalone variant command to the integrated preprocess workflow, adds project source snapshots and downstream invalidation, exposes stable workflow result/validation/version contracts, and provides a pinned production CPU container with acceptance and relocation coverage.
